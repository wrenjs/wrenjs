<header>
# Installation

Installing <span class=":uno: font-serif">wrenjs</span> is simple and straightforward. There are three options to get started:

- [Using the `create` **command** <Badge tint="green"><Icon name="i-lucide:check" /> Recommended</Badge>](#create-cli)
- [**Cloning** a starter template from GitHub](#clone-template)
- [**Manually** setting up a project and installing the dependencies](#manual-setup)

## Prerequisites

- <Icon name="i-simple-icons:nodedotjs" /> Node.js - Version 22 or higher.

- <Icon name="i-lucide:package" /> A preferred package manager, such as `npm`, `pnpm`, etc.

## Browser Support

<span class=":uno: font-serif">wrenjs</span> is built with
<Icon name="i-simple-icons:vite" className=":uno: size-3" /> Vite, which supports modern browsers
for development and builds - but does support legacy browsers with configuration. Check their
[browser support page <Icon name="i-lucide:external-link" />
](https://vite.dev/guide/build#browser-compatibility) for more details.

</header>

<section>
<h2 id="create-cli">Install with the `create` command <Badge tint="green" size="md"><Icon name="i-lucide:check" /> Recommended</Badge></h2>

It is commonplace for most frameworks to provide a small CLI tool to help developers quickly scaffold a new project. This will create a directory with the necessary files and install the required dependencies.

> <Icon name="i-lucide:info" /> **Did you know?** `npm create <package>` is shorthand for `npx create-<package>`, and `npm create <@namespace>` is shorthand for `npx <@namespace>/create`, meaning a `create-<package>` exists in the NPM registry.

<Steps>
    <Step>
      ### Create with CLI

      Our `create-wrenjs` CLI tool will give you guided prompts to help set up your project.

      <Terminal contents={`${LS_PKG_KEY} create wrenjs@latest`} />

    </Step>

    <Step>
      ### Start Development

      Once the CLI tool completes, you're ready to start development.

      <Terminal contents={["cd <my-app>", `${LS_PKG_KEY} run dev`]} />
    </Step>

</Steps>

<section>
  <h2 id="manual-setup">Manual Install</h2>

Installing <span class=":uno: font-serif">wrenjs</span> manually involves some simple file operations you're familiar with.

This example will attempt to create the _minimum necessary files_ to get a project up and running. Optional ones will be noted.

  <Steps>
    <Step>
      ### Create a new project directory
      In your terminal, you want to create a new directory for your <span class=":uno: font-serif">wrenjs</span> project and create a new `package.json` file.

      You can do this quickly with the following:

    </Step>

    <Step>
      ### Modify package.json
      Open the `package.json` file in your favorite text editor and add the following content.

      This ensures your <span class=":uno: font-serif">wrenjs</span> project has the necessary scripts to run development, build, and preview commands.

      <Terminal kind="file" contents={["\{", '  "scripts": \{', '    "dev": "wren dev",', '    "build": "wren build",', "  \}", '  "type": "module"', "\}"]} />
    </Step>

    <Step>
      ### Install dependencies
      Now you can install the required dependencies for <span class=":uno: font-serif">wrenjs</span>.

      <Terminal contents={`${LS_PKG_KEY} i @wren-js/core`} />

      You should also choose at least one [integration](#integrations-link) library.

      <Terminal contents={["# With React", `${LS_PKG_KEY} i @wren-js/react react react-dom`, "", "# With Preact", `${LS_PKG_KEY} i @wren-js/preact preact`]} />


    </Step>

    <Step>
      ### Create supporting directories and files.
      Now that you have dependencies installed, you're almost done!

      Next, you need to create the necessary configuration and directories the application looks for.

      You will also need to add the integration library you chose to the `wren.config.js` file.

      > <Icon name="i-lucide:info" /> Note that `wren.config.js` can also be named with a `.js`, `.mjs`, `.ts`, or `.mts` extension.

      <Terminal kind="file" contents={["mkdir -p src/pages"]} icon="i-lucide:terminal" path="Terminal"  />

      <Terminal class="mt-4" kind="file" contents={["import { defineConfig } from 'wrenjs';", "// Whichever you picked", "import react from '@wren-js/react';", "import preact from '@wren-js/preact';", "", "export default defineConfig(\{", "  // Whichever you picked","  integrations: [react()],", "  integrations: [preact()],", "  // ... Other configuration options ...", "\})"]} icon="i-lucide:file" path="wren.config.js" />
    </Step>

    <Step>
      ### Enable TypeScript <Badge tint="#ff0000" size="md"><Icon name="i-lucide:info" /> Optional</Badge> <Badge tint="green" size="md"><Icon name="i-lucide:check" /> Recommended</Badge>
      For TypeScript support to help with a better developer experience, you can install the TypeScript package and create a `tsconfig.json` file.

      <Terminal contents={`${LS_PKG_KEY} i -D typescript`} icon="i-lucide:terminal" path="Terminal"  />

      > <Icon name="i-lucide:info" /> All integrations come with a `base.json`, `strict.json`, and `strictest.json`.

      <Terminal kind="file" class="mt-4" contents={["{", "  // Whichever you picked", '  "extends": ["@wren-js/react/tsconfig/base.json"]', '  "extends": ["@wren-js/preact/tsconfig/base.json"]', "}"]} icon="i-lucide:file" path="tsconfig.json"  />
    </Step>

    <Step>
      ### Run the development server
      Now that you have everything set up, you can start the development server to see your application in action.

      <Terminal contents={`${LS_PKG_KEY} run dev`} icon="i-lucide:terminal" path="Terminal"  />
    </Step>

  </Steps>

That's it! You have successfully set up a new WrenJS project.

From here, you may install additional integrations, adapters, and other necessary packages for your project.

</section>
